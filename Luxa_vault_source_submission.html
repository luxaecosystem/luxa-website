LUXA Vault — Spider's Nest

Technical documentation accompanying the extension's source code review, with instructions to reproduce the single bundled artifact included in the package.

01 — CONTEXT

Overview

"Spider's Nest" is the non-custodial wallet extension for the LUXA ecosystem (luxa-1 chain). This document accompanies the source code archive submitted for review and explains how to reproduce the third-party library included in the package.

03 — SETUP

Installation

  1. Extract the source code archive.
  2. Open a terminal in the root directory.
  3. Install the required npm packages:
npm install

04 — BUILD

Reproducing the bundled library

The extension bundles CosmJS for offline, browser-only execution (no network call fetches or updates it at runtime). To reproduce the exact bundle included in the package:

npm run build

This script invokes esbuild using bundle-entry.js as the entry point and produces the artifact libs/cosmjs.bundle.js, identical to the one shipped inside the package. No transformation is applied after the build step — the shipped artifact is the direct build output.

What the bundle is used for: CosmJS is used exclusively client-side to derive keys/addresses from a locally generated BIP-39 seed phrase, sign outgoing transactions on the luxa-1 chain before broadcasting, and read on-chain balances via public RPC endpoints. No seed phrase, private key, or derived material is ever transmitted off-device.
